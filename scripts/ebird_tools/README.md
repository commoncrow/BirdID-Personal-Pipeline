# eBird Workflow Tools

This directory contains standalone Python tools intended to extend SuperPicky's categorization into an automated, highly-aesthetic eBird upload and checklist pipeline.

---

## 📋 Comprehensive Workflow Details

The automated pipeline executes the complete end-to-end processing of your bird photography from raw camera directories to eBird checklists. The workflow follows this step-by-step sequence:

### Step 1: Initial Photo Evaluation & Rating
* **Process**: Scans the target raw directory (or camera subfolders like `100NIKON`) using the SuperPicky model. Ratings are applied, and photos are organized into technical star subfolders: `3star_excellent`, `2star_good`, `1star_average`, and `0star_reject`.
* **Usage**: `uv run python superpicky_cli.py process <Target_Folder> -s <sharpness_threshold> -n <nima_threshold>`

### Step 2: Bird Species Identification (BirdID)
* **Process**: Scans all `Other_Birds` directories inside the `3star_excellent` and `2star_good` folders. YOLO-based bird species identification is executed to automatically categorize photos into species-specific folders and write metadata.
* **Usage**: `uv run python birdid_cli.py organize <Other_Birds_Folder> -y --write-exif`

### Step 3: Clean Up Output (Remove Chinese Prefixes)
* **Process**: Cleans folder names generated by BirdID by removing Chinese name prefixes and retaining only English common names.
* **Script**: `remove_chinese_names.py`
* **Usage**: `python scripts/ebird_tools/remove_chinese_names.py <Other_Birds_Folder_1> [Folder_2 ...]`
* **Example**: `ChinesePrefix_White-browed Scimitar Babbler` ➔ `White-browed Scimitar Babbler`

### Step 4: Unique Species List
* **Process**: Scans all categorized folders and generates a sorted, unique list of all photographed species in `unique_bird_species.txt` at the target root.

### Step 5: Segregate Flying Birds
* **Process**: Uses ExifTool to batch-scan the `XMP:Description` field in all JPGs for the tag `Flying: Yes` (assigned by SuperPicky). Matches are moved (with paired RAW + XMP sidecars) to a `flying_birds/` subfolder at the star folder root level, then sharpened.

### Step 6: Segregate Picked/Flagged Photos
* **Process**: Identifies top-flagged photos inside `3star_excellent` where `XMP:Rating` = 5 or `XMP:Label` = "Pick"/"Red". Moves them with sidecars to a `picked/` star root folder, then applies the chosen sharpening tool.

### Step 7: Aesthetic Scoring (SigLIP)
* **Process**: Runs a Google SigLIP-based aesthetic model (`aesthetic-predictor-v2-5`) to score all JPGs on a scale of 1–10. Exports the best-composed photos (above user threshold, e.g., >= 6.0) into `<Target>/top_aesthetic/` alongside original RAW pairs, highlighting "hidden gems" found in lower star rating folders.

### Step 8: Prepare eBird Uploads (Highest-Rated Selection)
* **Process**: Scans categorized folders and automatically selects the single highest-rated photograph for each unique species across all shooting dates, staging them in an `upload_ready/` directory. All files are named cleanly after the English common name of the species.
* **Script**: `prepare_ebird_upload.py`
* **Usage**: `python scripts/ebird_tools/prepare_ebird_upload.py <Target_Folder>`

### Step 9: Automatic Highlights & Shadows Tuning
* **Process**: Performs per-image aesthetic tone corrections on `upload_ready` JPEGs using OpenCV in the LAB colorspace. Automatically lifts underexposed shadows and compresses blown highlights while fully preserving midtones.

### Step 10: YOLO Centered Bounding-Box Crop & Sharpen
* **Process**: Uses the YOLO bird detector model to automatically locate the bird inside each staged upload JPEG. Extracts a highly-aesthetic cropped bounding box (with an 80% padding margin so the subject sits beautifully in the frame) and applies an Unsharp Mask filter pass.
* **Script**: `crop_and_sharpen.py`
* **Usage**: `python scripts/ebird_tools/crop_and_sharpen.py <Target_Folder>\upload_ready`

### Step 11: Auto-Fill eBird Checklists
* **Process**:
  1. Launches Chrome with remote debugging on port `9222`.
  2. Scans photo Exif data using ExifTool to match photographed species strictly with their exact shooting dates.
  3. Queries your eBird account to automatically discover checklists representing those dates.
  4. Opens the target checklists in Chrome tabs.
  5. Types and autocompletes each missing species.
  6. Locates the correct `<li>` species count input (using leaf-level precise targeting) and enters count `"X"` (Present) without overwriting manual numbers.
  7. Highlights rows in soft green (`#e8f5e9` background, `#2e7d32` left border) for easy manual review.
* **Script**: `ebird_add_missing_species.py`
* **Usage**: `python scripts/ebird_tools/ebird_add_missing_species.py <Target_Folder> [--report-only]`

## 🛠️ Setup & Prerequisite Requirements

To run this automated pipeline successfully, ensure the following setup is configured:

1. **Python Dependencies**:
   * Install required packages:
     ```bash
     uv pip install websocket-client pillow opencv-python numpy torch aesthetic-predictor-v2-5
     ```

2. **Chrome Remote Debugging**:
   * Chrome must be running with remote debugging enabled on port `9222`:
     ```bash
     chrome.exe --remote-debugging-port=9222 --remote-allow-origins=*
     ```

3. **ExifTool Path**:
   * ExifTool is used to extract shooting metadata. The scripts automatically detect the executable relative to your OS in `exiftools_win/exiftool.exe` or `exiftools_mac/exiftool`.

4. **Geocoding & Location Cache**:
   * Geocoding utilizes the free OpenStreetMap Nominatim API. Resolved locations are stored locally in `<Target_Folder>/location.json` to prevent repeated lookups and prompts.
