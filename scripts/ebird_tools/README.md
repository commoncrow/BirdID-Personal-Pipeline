# eBird Workflow Tools

This directory contains standalone Python tools intended to extend SuperPicky's categorization into an automated eBird upload pipeline.

## Tools Included

### 1. `remove_chinese_names.py`
Removes the Chinese name prefixes from species folders generated by `birdid_cli.py` (e.g. `灰头钩嘴鹛_White-browed Scimitar Babbler` -> `White-browed Scimitar Babbler`) and updates the hidden `.birdid_manifest.json` tracker file.
* **Usage**: `python remove_chinese_names.py <dir_path_1> [dir_path_2 ...]`

### 2. `prepare_ebird_upload.py`
Scans the `Other_Birds` folders in both the 3-star and 2-star directories. Selects the highest rated available photo for each unique species, and stages them by copying them into an `upload_ready` folder. All copied photos are given proper English filenames based on their species.
* **Usage**: `python prepare_ebird_upload.py <superpicky_target_root_folder>`

### 3. `crop_and_sharpen.py`
Processes a folder of JPG photos (usually the `upload_ready` directory). It uses SuperPicky's YOLO model to extract a highly-aesthetic crop bounding box (with an 80% padding margin so the bird fits beautifully in the frame) and then applies an Unsharp Mask filter to improve photo clarity.
* **Usage**: `python crop_and_sharpen.py <upload_ready_folder_path>`

## Automated Application Structure
These tools can be sequentially run as a unified process via the agent workflow command located in `.agents/workflows/ebird_processing.md`.
